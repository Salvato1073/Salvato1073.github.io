# Campus Godin
Progressive Web App (PWA) personnelle pour Godin Liberal Arts 2026–2027.

- Entrée quotidienne via le Directeur des études
- Accès directs aux cours et services
- Raccourcis 20 min / 1 h / fatigue
- Reprise du dernier espace ouvert
- Claude et Gemini comme outils secondaires
- Installation sur écran d'accueil Android
